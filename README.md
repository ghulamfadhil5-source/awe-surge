One image made to excite the AI judge: a colossal glass phoenix shattering
into a flock of glowing birds above a night city. Entry for the make.fun
bounty [Make the AI judge excited](https://make.fun/bounty/ai-excited-01).

`main.ts` (Node 22, standard library only) copies `entry.png` to
`/output/entry.png`, byte for byte, deterministically.
